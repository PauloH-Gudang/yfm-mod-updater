    Compilar agora
    

    O site envia o mod para o seu repositório do atualizador, o GitHub compila e o site baixa os .o prontos. Precisa de um token do GitHub (fine-grained, só esse repositório, permissões Contents: Read and write e Actions: Read). O token fica só neste navegador.
    

    



    

    

    

    

    

    Como os arquivos de build são gerados

    O navegador não consegue rodar o clang do jogo, então o .zip leva junto três formas de compilar, todas usando o build_mod.py oficial:
    

      

    • Pelo botão "Compilar agora" (site aberto pelo GitHub Pages ou pelo index.html no seu PC): tudo automático.
      • 

    • Na nuvem, à mão: extraia a pasta do mod em mods/ do repositório do atualizador e faça push. O workflow compila e devolve, em Actions → Artifacts → mods-compilados, o mod com .o e .x86_64-windows.o.
      • 

    • Windows: dê dois cliques em BUILD-WINDOWS.bat e informe a pasta sdk do release do jogo. Ele chama o build-mod.bat do SDK, que gera também o .aarch64-translated.o (Android).
      • 

    • Linux: ./build-linux.sh /caminho/do/release/sdk.
      • 

    

    


    O que este site corrige
    

    Ver lista

    mod.json
      

    • BOM, comentarios // e /* */, virgulas sobrando, números hex soltos (0x5D800 vira "0x5D800") e números com zero à esquerda.
      • 

    • Calcula o min_api mínimo pelos recursos usados (tabela "Which game a mod needs").
      • 

    • Chaves com erro de digitação (libary → library), hand_colour → hand_color, enabled/restart em texto.
      • 

    • Mod com .c e sem library: adiciona. Remove de libraries o alvo aarch64 (Android antigo de memória fixa).
    

    Código C (para compilar em 64 bits e Android)
      

    • mod->api = 12 → MEMORIES_MOD_API.
      • 

    • Declarações próprias de D_800E9D90…D_800E9D9C / D_800E9DB0 → #include "game/ordering_tables.h" / "game/main_services.h" (sem isso o x86_64 não compila).
      • 

    • Casts ponteiro↔inteiro ((u32)&x, (void*)0x8001…) passam por uintptr_t.
      • 

    • printf/fprintf(stderr,…) → host->log; headers de sistema proibidos removidos.
      • 

    • Avisos (sem mudança automática): long com funções GTE (use PSXLONG), fopen/getenv/time/exit, entradas novas do host sem checar host->api.
      • 

    • Remove objetos antigos (.o sem thunks, .aarch64.o): eles serão recompilados.
